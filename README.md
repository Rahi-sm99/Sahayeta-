# Sahayeta (सहायता) - Smart Mission Control

**Sahayeta** (Hindi: सहायता, meaning Assistance) is an AI-powered GIS Command Center designed for high-efficiency humanitarian aid coordination. It synchronizes NGOs and volunteers through a dual-portal ecosystem, enabling real-time mission matching and geospatial deployment tracking.

---

## 🚀 Key Features

*   **AI Matching Engine**: Smart ranking of volunteers based on skills, experience, and proximity.
*   **GIS Command Center**: Real-time tactical map for monitoring mission hotspots across India.
*   **Live Simulation**: Animated deployment tracking showing agent paths from origin to mission target.
*   **Unified Agent App**: Mobile-first Flutter application for vetted field agents.
*   **Decision Intelligence**: Urgency-scored dashboards for optimized resource allocation.

## 🛠️ Technology Stack

*   **Frontend**: React 18 + Vite (Premium Dark Mode UI)
*   **Mobile**: Flutter (Dart) for Android/iOS
*   **Backend**: Supabase (PostgreSQL, Realtime Sync, OAuth)
*   **Mapping**: Google Maps JavaScript API
*   **Animations**: Framer Motion & Flutter Animate

---

## 📦 Getting Started

### Web Portal
1. Clone the repository.
2. Run `npm install`.
3. Start development: `npm run dev`.

### Mobile App (Flutter)
1. Navigate to the `application` folder.
2. Run `flutter pub get`.
3. Launch on device: `flutter run`.
